# CareBridge 真实模型对话接入

当前版本在原四端 HTML 上增加 Python 服务端网关，默认调用 DeepSeek V4.1 Flash（API 模型名 `deepseek-flash`）。不依赖第三方 Python 包。

## 启动

1. 安装 Python 3.10 或更新版本。
2. 将 `.env.example` 复制为 `.env`，在本机填写 `DEEPSEEK_API_KEY`。不要将密钥发到群聊或写进 HTML。
3. 在项目目录运行 `python server.py`。
4. 浏览器打开 http://127.0.0.1:8000 ，选择角色并进入。不要双击 HTML 文件启动。

密钥只由服务端读取；修改 `.env` 后需重启。模型接口请求官方 HTTPS 地址。默认只监听本机，静态文件采用白名单，不提供 `.env` 和文档下载。手机演示使用 HTTPS 隧道，`DEMO_PASSWORD` 留空可直接进入；设置后增加浏览器访问认证。详见 [手机访问与语音配置](手机访问与语音配置.md)。演示入口密码不能替代生产级身份认证与患者授权。

## 已实现

- 统一入口和四个独立入口均使用同一个 `agent.js`。
- 真实多轮模型对话，最近 30 条接入后的消息作为上下文；旧的固定回复不作为模型历史。
- 模型可调用 `get_care_context`，服务端执行白名单工具并把结果送回模型，最多 4 轮。页面显示工具执行记录。
- 工具查询浏览器当前 tasks、readings、meals；只发送这些字段，排除图片与个人资料。它们仍是本地原型数据，不是后端医疗记录。
- 等待提示、防重复发送、错误提示及失败重试。未配置密钥、余额不足、限流和网络超时不会伪装为成功。
- 不提供自动发布医嘱、修改用药或确认服药的写工具。

## 仍需完成

功能清单并未全部落地。真实登录及四端授权、共享数据存储、医嘱版本、发布确认、跨端事件、后台通知、OCR 和设备接入仍是后续工作。语音录入已接入真实录音与 Qwen-ASR 接口，需要单独配置百炼密钥，识别文字须核对后发送。其他业务按钮保持原型行为。

本地自动测试使用替代模型响应，只验证工具编排、语音音频处理和接口边界，不代表真实云端调用已通过。上海话识别效果及手机麦克风兼容性需要配置语音服务后进行真机验收。

## 检查

运行 `python -m unittest discover -s tests -v`，以及 `node --check agent.js`。

模型接口参考：https://api-docs.deepseek.com/api/create-chat-completion/

## 文件

`server.py`：本地服务、参数验证、模型请求、工具循环。`agent.js`：四端对话接入。`演示说明.md`：录屏流程及说明文案。原功能清单保留用于周末逐项验收。


## 四角色测试资料与用药任务下发

每种角色已自动预置完整虚构资料，新版本首次进入会按用户要求直接覆盖旧本机记录。角色查询工具支持医嘱、草稿反馈、近三天记录和社区事项。家属可使用服务器预置的已确认演示医嘱发布 7 天每日用药提醒，老人端轮询接收并本人确认，家属端同步完成状态。任务保存在 `.runtime/shared-tasks.sqlite3`，请保留该文件；其他角色本机记录尚未全面同步。

操作与验收见 [AI 总结与下发任务测试](CareBridge_AI总结与下发任务测试.md)。


## 三端动态互通

医生可以按患者照护关系选择家属发送医嘱，家属按收到的有效版本下发每日用药任务或添加日常任务，患者确认后医生和家属读取状态。医嘱更新会停用旧版用药任务，记录保留。共享服务实现位于 `collaboration.py`，`shared_tasks.py` 保留兼容导入，客户端使用 `workflow-sync.js`。

演示账号、实际操作及范围见 [三端动态演示](CareBridge_三端动态演示.md)。
